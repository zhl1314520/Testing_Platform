# Testing Platform 设计文档

## 1. 平台总体目标

- 支持小团队进行 **自动化测试、接口测试、UI测试、性能测试**。
- 提供 **测试用例管理、测试数据管理、报告管理、持续集成/持续交付(CI/CD)对接**。
- 支持 **权限管理、团队协作、日志和告警**。
- 尽量 **低维护成本、易扩展**，支持未来企业级扩展。

## 2. 架构设计

### 2.1 架构层级

1. **用户层（Web）**
   - 测试用例管理
   - 测试计划与执行
   - 报告查看与导出
   - 日志/监控查看
2. **应用层（服务端 API）**
   - 用户权限管理服务
   - 测试用例管理服务
   - 测试执行调度服务
   - 测试数据管理服务
   - 报告生成服务
   - 通知/告警服务（邮件）
3. **执行层**
   - **测试执行引擎**
     - API测试引擎（Postman、Requests、Pytest）
     - UI测试引擎（Selenium、Playwright）
     - 性能测试引擎（Locust、JMeter）
   - **测试数据服务**（Mock Server / 数据库 / 文件）
4. **存储层**
   - 数据库（MySQL、Redis）
     - 用户表、角色权限表
     - 项目表、测试计划表、用例表、执行记录表
   - 文件存储（测试报告、日志、截图）
   - 日志系统（Elasticsearch + Kibana 或简单文件系统）

## 3. 核心功能模块设计

### 3.1 用户与权限管理

- 用户注册/登录（可集成LDAP/SSO）
- 角色管理：管理员、测试工程师、开发人员
- 权限控制：用例查看、执行、编辑、报告导出
- 审计日志：操作记录

### 3.2 项目/测试计划管理

- 每个测试项目独立管理
- 创建测试计划（包含用例集、执行时间、环境）
- 支持循环执行/定时执行
- 关联CI/CD流水线

### 3.3 测试用例管理

- API测试用例（GET/POST/PUT/DELETE）
- UI测试用例（录制/脚本）
- 数据驱动测试（JSON）
- 用例版本控制（可回滚）
- 用例目录/标签/标签组
- 集成 Mock 服务

### 3.4 测试执行与调度

- 执行方式：手动、定时、CI/CD触发
- 并发执行、异步任务调度
- 多环境支持（Dev/Test/Pre/Prod）
- 执行监控：实时状态、执行日志、截图、报错信息

### 3.5 测试数据管理

- 数据管理：数据库测试数据、文件数据上传/下载、Mock数据生成
- 数据隔离：各项目/测试计划独立数据环境
- 数据回滚：测试完成后恢复原始状态

### 3.6 报告与分析

- 报告类型：HTML、PDF导出、统计通过率/失败率
- 缺陷统计：关联Bug系统（Jira/GitLab）
- 趋势分析（按天/周/月）
- 失败用例分析、覆盖率分析

### 3.7 通知与告警

- 通知方式：邮件
- 告警触发：执行失败、环境异常、定时任务异常
- 日志中心：执行日志集中管理，支持查询/导出

### 3.8 CI/CD 集成

- Jenkins/GitLab CI/TeamCity触发执行
- 回传执行结果到CI页面
- 可选失败阻断流程

## 4. 技术栈建议

| 模块      | 技术建议                                       |
| --------- | ---------------------------------------------- |
| 前端      | Vue3 + Element UI                              |
| 后端      | Python (FastAPI)                               |
| 数据库    | MySQL + Redis                                  |
| 测试引擎  | Pytest、Requests、Selenium、Playwright、Locust |
| 消息队列  | RabbitMQ / Redis Queue（任务调度）             |
| 日志/监控 | ELK Stack 或简单文件 + Grafana                 |
| 报告生成  | Allure 或自定义 HTML/PDF                       |
| CI/CD     | Jenkins/GitLab CI/Argo CD                      |

## 5. 平台示意流程

1. 用户注册 → 登录 → 选择项目 → 创建测试计划
2. 添加测试用例（API/UI） → 关联测试数据
3. 触发执行（手动/定时/CI） → 测试引擎执行
4. 收集结果 → 生成报告 → 发送通知/告警
5. 报告分析 → 趋势统计 → 缺陷追踪
